AI Upscaler ×4

Phóng to ảnh gấp 4 lần bằng Real-ESRGAN, chạy ngay trên GPU của máy bạn: không tải ảnh lên server nào, xuất PNG gắn DPI sẵn sàng để in.

Xem mã nguồn trên GitHub
Kéo thả trong trình duyệtGiao diện web chạy cục bộ, upscale nhiều ảnh, tải kết quả từng ảnh.
Dùng cho in ấnGắn DPI (mặc định 300) vào file, hiển thị kích thước in theo cm.
Ảnh lớn không lo VRAMXử lý theo tile có padding, không lộ đường nối.
CLI xử lý hàng loạtUpscale cả thư mục bằng một lệnh.

Cài đặt

git clone https://github.com/toiladuyminh1997-ui/ai-upscaler
cd ai-upscaler
pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt

Sử dụng

# Web app (tự mở http://127.0.0.1:7860)
python app.py

# Dòng lệnh
python cli.py anh1.jpg anh2.png --dpi 300

Lần chạy đầu tự tải model RealESRGAN_x4plus.pth (~64 MB). Có GPU NVIDIA sẽ nhanh hơn nhiều; không có vẫn chạy được bằng CPU.

Model: Real-ESRGAN (BSD-3-Clause).
